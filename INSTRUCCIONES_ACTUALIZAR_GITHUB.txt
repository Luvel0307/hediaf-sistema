INSTRUCCIONES PARA ACTUALIZAR GITHUB Y CORREGIR DEPLOYMENT
===============================================================

PROBLEMA:
- Render usaba Python 3.14.3 por defecto
- scipy 1.13.1 no se puede compilar sin gfortran en Python 3.14
- tensorflow-cpu 2.16.2 y keras 3.3.3 tenían incompatibilidades

SOLUCIÓN APLICADA:
- Se creó runtime.txt para forzar Python 3.11.9
- Se creó .python-version como alternativa
- Se actualizó requirements.txt con versiones precompiladas (wheels)
- tensorflow-cpu 2.15.0 + keras 2.15.0 (más estable y ligero)
- scipy 1.11.4 (tiene wheels precompilados para Python 3.11)

PASOS PARA ACTUALIZAR EL REPOSITORIO:
---------------------------------------------------------------
1. Abre una terminal en la carpeta del proyecto:
   cd ruta\a\hediaf_deploy

2. Verifica los cambios:
   git status

3. Agrega todos los archivos modificados:
   git add .

4. Haz el commit:
   git commit -m "Fix: Usar Python 3.11.9 y versiones compatibles para Render"

5. Sube a GitHub:
   git push origin main

6. Render detectará los cambios automáticamente y redesplegará.

NOTA: Si el deploy sigue fallando, verifica en Render Dashboard:
- Settings > Environment > PYTHON_VERSION debe ser 3.11.9
- El build log debe mostrar "Using Python version 3.11.9"
